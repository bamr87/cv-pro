# Page feedback widget — evidence (issue #13)

> **Feature:** `CVPRO-006` in `features/features.yml` · **Scenario:** `verify/scenarios/page-feedback.yml` · **Generated by:** `node verify/runner.mjs --only page-feedback --stamp --by agent` against `vite preview` of `npm run build` (`http://127.0.0.1:4613`) on 2026-11-16 · **Verified by:** agent (local run, Playwright 1.65 Chromium)

A reader of CV Builder Pro can now report a problem with the page they are on: the fleet's "Improve this page" button sits bottom right on every route, a matching link sits in the header ("Feedback" below 640px), and both open one dialog that builds a prefilled GitHub issue on `bamr87/cv-pro`. BEFORE: on `main` the same scenario fails at step 3 on both viewports, because no `<fleet-feedback>` element is mounted and the kit in the repository-root `public/` is never served (`before-*.png`). AFTER: all 22 steps pass on both viewports. A `console.error` probe lands in `window.__fleetFeedback.snapshot()`, and submitting the dialog with `window.open` stubbed yields exactly one URL, `https://github.com/bamr87/cv-pro/issues/new`, with the labels `page-feedback,bug`, the marker `<!-- fleet-feedback v1 type=fix-page -->` and the probe line in its body. The page has no horizontal overflow (scrollWidth equals clientWidth: 1280 and 390), and the scenario saw no console error of its own.
